MWC deployment mapping for Hermes/Telegram

Public host:
- https://mwc.gtixt.com

Active vhost / TLS routing source:
- /opt/txt/docker/mwc-tls.conf
- server_name: mwc.gtixt.com
- HTTPS upstream: http://mwc-landing:80

Active content source served by mwc-landing:
- Host path: /opt/txt/sites/mwc
- Live file: /opt/txt/sites/mwc/index.html
- Docker mount: /opt/txt/sites/mwc -> /usr/share/nginx/html (container: mwc-landing)

Telegram/Hermes bridge path:
- /opt/hermes/data/home/dropshipping-ops/mwc-site-bridge
- Bridge file: /opt/hermes/data/home/dropshipping-ops/mwc-site-bridge/index.html
- This bridge file is a hard link to the live file above.
- Editing the bridge index.html updates the live site immediately.

Important runtime limit:
- hermes-gateway mounts /opt/hermes/data only.
- hermes-gateway does NOT see /opt/txt.
- For brand new assets/files, place them in the bridge first, then publish with publish_new_assets.sh from the host context if needed.
